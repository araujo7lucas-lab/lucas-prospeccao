Sincronizar tablet e computador

Trabalhe offline nos dois aparelhos. Quando quiser juntar o que cada um anotou: gere o arquivo de sincronização em um aparelho, leve ao outro (WhatsApp, e-mail, Drive, cabo USB ou Bluetooth) e aplique lá. Repita no sentido contrário para os dois ficarem iguais. Nada é apagado: se o mesmo campo foi editado nos dois, vale a edição mais recente.

Antes de viajar
  1. Abra o programa com internet e confira que o aviso no topo diz “pronto para offline”.
  2. Importe as planilhas e, na tela Mapa, use “Localizar cidades com precisão”.
  3. Gere um backup e um arquivo de sincronização.

Importar planilhas (.xlsx, .xls, .csv)

Dados oficiais vêm de base governamental e ficam somente neste navegador. O navegador pode apagar dados locais: faça backup com frequência.
